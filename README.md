# Bus Management System

A console-based Bus Management System developed in C.

## Features

- Search bus routes
- Book seats
- Cancel booked seats
- View seat map
- Submit passenger feedback
- Manage bus and passenger information

## Data Structures Used

- Linked List
- Array
- Queue

## Technologies Used

- C Programming Language
- File Handling

## Project Files

- `main.c` — Main source code
- `bus.txt` — Stores bus-related information
- `passenger.txt` — Stores passenger-related information
